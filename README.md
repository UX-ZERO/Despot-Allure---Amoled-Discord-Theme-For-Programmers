# Despot Allure v16 — AMOLED Terminal Theme for Discord

> **This theme is a passion project** crafted for developers, terminal enthusiasts and users who prefer high-contrast, pure AMOLED black aesthetics and precise typography.

---

## Overview

**Despot Allure** is a heavily customized, high-performance Discord theme built on top of the `system24` framework. Designed to reduce visual clutter, maximize screen real estate for code blocks and chats and emulate a sleek, programmer-friendly terminal-like environment.

This repository represents a personal labor of love—tweaked, optimized and refined to achieve absolute visual consistency, razor-sharp geometric alignment.

---

## Key Features

* **Pure AMOLED Black (`#000000`):** Perfect for OLED displays to completely eliminate grey patches, reduce eye strain in dark environments and maybe even save power.
* **Programmer Typography:** Integrated support for elite monospace font stacks (`IBM Plex Mono` and `JetBrains Mono`) for crystal-clear code blocks, message text and UI elements.
* **Terminal Panel Labels:** Clean, bracketed architectural UI labels (`[nav]`, `[channels]`, `[chat_log]`, `[user]`, `[members]`) that give your Discord client a custom developer HUD feel.
* **Compact Layouts & Custom Scrollbars:** Slimmed-down, unobtrusive scrollbars and tightly aligned chat input bars to maximize information density.
* **Custom ASCII Bootloader:** Features a custom ASCII text loader element on startup.

## Prerequisites

To use this theme, you will need a custom Discord client mod that supports custom CSS injection:

* [Vencord](https://vencord.dev) (Recommended)
* [Testcord](https://www.testcord.dev)
* [BetterDiscord](https://betterdiscord.app)

---

## Installation

1. Open your Discord client mod settings (e.g., Vencord settings).
2. Navigate to the **Themes** tab.
3. Create a new custom theme file or paste the contents of `Despot Allure v16 Optimized_2.css` into your local user CSS file.
4. Ensure you have internet access enabled for the initial load so the Google Fonts and base dependencies (`system24`) can resolve correctly via `@import`.

---

## Customization

The theme utilizes CSS variables for easy tweaking. You can modify the root variables directly inside the CSS file to adjust font choices, spacing, and panel behaviours to match your exact workflow setup.
